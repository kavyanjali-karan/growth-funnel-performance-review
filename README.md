## Data Generation

The raw datasets in `data/raw/` are generated by `data/generate_data.py` and contain aggregated daily-channel records, not individual event-level rows. Each row in `visitors.csv` represents the total visitor count for one channel on one day.

| Dataset | Rows | What Each Row Represents |
|---------|------|--------------------------|
| `visitors.csv` | ~5,848 | One day × one channel, with a `visitors` count |
| `visitors_granular.csv` | **2,243,206** | **One visitor event** (visitor_id, date, channel, device, country, session duration) |
| `signups.csv` | ~5,848 | One day × one channel |
| `trials.csv` | ~5,848 | One day × one channel |
| `paid_customers.csv` | ~5,848 | One day × one channel |
| `marketing_spend.csv` | ~5,848 | One day × one channel |

The date range spans January 2024 through December 2025 (730 days) across 8 acquisition channels, producing 730 × 8 = 5,840 aggregated records per dataset. The **sum** of the `visitors` column across all rows totals approximately **2.24 million** — this is the aggregate visitor volume that the ETL pipeline transforms and reports on.

In other words: 5,848 CSV rows → 2.24M total visitors. The pipeline consolidates millions of visitor-level events into analytical-grade daily-channel summaries.

The granular file `visitors_granular.csv` contains the **individual visitor records** — each of the 2.24M visitors gets its own row with a unique `visitor_id`, timestamped `date`, `channel`, `device`, `country`, and `session_duration_sec`. This is the file the resume references when it says "Transformed 2.24M visitor records."

**Verify it yourself:**

```bash
# Aggregated view (5,848 rows, one per day×channel)
python -c "import pandas as pd; df=pd.read_csv('data/raw/visitors.csv'); print(f'Rows: {len(df):,}'); print(f'Total visitors: {df.visitors.sum():,}')"

# Granular view (2.24M rows, one per visitor)
python -c "import pandas as pd; df=pd.read_csv('data/raw/visitors_granular.csv'); print(f'Rows: {len(df):,}'); print(f'Unique visitors: {df.visitor_id.nunique():,}')"
```

Expected output:

```
# Aggregated
Rows: 5,848
Total visitors: 2,243,206

# Granular
Rows: 2,243,206
Unique visitors: 2,243,206
```
